# Test teasers (fictional)

Sample teasers for trying SearchDesk's AI teaser reading. Every business, person, number, and contact detail is made up.

| File | How to use it | What Claude should fill in | What should stay blank |
| --- | --- | --- | --- |
| `teaser-granite-ridge.txt` | Copy the text and paste it into "Paste a teaser" | Name, HVAC description, Commercial services, NH, $3.1M price, SDE $780K, $3.58M revenue, slow growth, retiring, Ellen Park (Broker) | Nothing important |
| `teaser-project-evergreen.pdf` | Click "Upload PDF" and choose this file | Project Evergreen, landscaping/snow removal, NJ, EBITDA $1.1M, $5.2M revenue, Marco Delgado (Broker) | Asking price, growth, reason for sale (not stated in the teaser) |
| `teaser-project-evergreen.txt` | Same teaser as plain text, for pasting | Same as the PDF | Same as the PDF |

The Evergreen teaser deliberately leaves out the price, growth trend, and reason for sale, to check that the AI leaves those fields blank instead of guessing.
